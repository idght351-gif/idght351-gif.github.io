Privacy Policy

Last updated: 2026-11-11

Baekho Shorts Manager (“the tool”) is a private tool used only by the owner of the YouTube channel “직장인 백호”. It is not offered to the public.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information accessed

  • YouTube Analytics data of the owner's channel (views, watch time, retention, revenue after monetization)
  • Information about the owner's videos (titles, descriptions, tags, playlists, comments)
  • Permission to upload, edit and delete videos on the owner's channel

How information is used

Only to upload and update the owner's own videos when the owner asks, and to write private performance reports for the owner. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Sharing

Information is not sold, shared with, or disclosed to any third party, and is not used for advertising.

Storage

OAuth tokens and reports are stored only on the owner's personal computer. No cookies or tracking are used, and no data is stored on any server.

Retention and deletion

  • Analytics data is refreshed every week; the previous copy is overwritten. Stored API data is deleted within 30 days if it is no longer refreshed.
  • Access can be revoked at any time at Google security settings (myaccount.google.com/permissions). After revoking, all stored tokens and data are deleted within 7 days.
